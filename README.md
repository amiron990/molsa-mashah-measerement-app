# מצפן רשויות מקומיות

מפת מדדים להערכת איכות עבודת המחלקות לשירותים חברתיים · אגף בכיר איכות, פיקוח ובקרה.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | **משימה 1** — מסך תפיסת המדידה: עץ הנושאים, משפך המיפוי, מקורות הנתונים, כרטיסי המדדים והדירוג |
| `workshop.html` | **משימה 2** — כלי הסדנה: הדשבורד ב-IFRAME + שאלות מכווינות לכל אחד משלושת מסכיו |
| `assets/app.css` | מערכת העיצוב (מבוססת מסמך "עקרונות עיצוביים ופלטת צבעים") |

| `assets/concept.js` | הלוגיקה של מסך תפיסת המדידה |
| `assets/workshop.js` | הלוגיקה של כלי הסדנה — כתובת הדשבורד (`DASH_BASE`) ומאגר השאלות (`SCREENS`) |
| `tools/gen_data.py` | בונה את `assets/data.js` מקבצי ה-CSV |

## רענון הנתונים

הנתונים נבנים מארבעה קבצי CSV שנמצאים בתיקיית האב (`../`):

- `רשימת מדדים משחים.csv` — טבלת ה-DIM של המדדים
- `מספר אינדקטורים לפי נושא ותת נושא.csv` — חמשת הנושאים ו-17 תתי הנושאים
- `נתונים ארציים מדדי מחלקות.csv` — סדרות עת ברמה ארצית
- `נתוני נפות מדדי מחלקות.csv` — אותן סדרות ב-12 נפות

לאחר עדכון קובץ מקור:

```bash
python tools/gen_data.py
```

## מה מוצג

- **28 מדדים** בטבלת ה-DIM, מהם **18 מדדים ראשיים** (10 הנוספים הם פירוט איוש תקנים לפי תפקיד) ו-**15 מוצגים במפת המדדים**.
- **14 מדדים** מגיעים עם סדרת עת — ארצית ולכל אחת מ-12 הנפות.
- מספרי משפך המיפוי (156 → 60 → 32 → 18) לקוחים ממצגת המתודולוגיה ומוגדרים ב-`tools/gen_data.py` (משתנה `funnel`).

## דירוג המשתמשים

בכניסה למסך המשתמש מתבקש לציין שם ונפה. נאספים שני סוגי משוב:

1. **דירוג מדד** — 1–5 כוכבים והערה חופשית, בכרטיס המדד.
2. **חיבוב תת נושא** — לייק / דיסלייק על כל אחד מ-17 תתי הנושאים במפת הנושאים, כדי לזהות אילו תתי נושאים בכל נושא חשובים למשתמשים. לחיצה חוזרת על אותו כפתור מבטלת את הסימון.

- הכול נשמר ב-`localStorage` של הדפדפן תחת המפתח `kyd_molsa_compass_v1` (`ratings` למדדים, `subvotes` לתתי הנושאים, במפתח `נושא§תת נושא`).
- כפתור **"ייצוא הערכות"** מוריד CSV אחד (עם BOM, נפתח נכון באקסל) עם עמודת **"סוג רשומה"** — `מדד` או `תת נושא` — כך ששני סוגי המשוב ניתנים לניתוח יחד:

  `סוג רשומה, שם המשתמש, נפה, נושא, תת נושא, מזהה מדד, שם המדד, דירוג (1-5), סימון תת נושא (1 חשוב / -1 פחות), הערה, עודכן`

- **לשליחה לשרת:** הגדירו כתובת במשתנה `SUBMIT_URL` בראש `assets/concept.js`. כל שמירה תישלח אליה כ-POST עם גוף JSON, במקביל לשמירה המקומית. בגוף הבקשה שדה `kind` מבחין בין `indicator` (עם `stars`/`note`) לבין `sub` (עם `vote` בערך 1 או 1-).

## כלי הסדנה (משימה 2)

הדשבורד: `http://biportal/Reports/powerbi/BokerTovManager/Gap_Analyzer_Mashah` (מוטמע עם `?rs:Embed=true`).
הוא מוצג בצד ימין, והשאלות בצד שמאל.

- **המעבר בין מסכי הדשבורד נעשה בתוך הדשבורד עצמו.** בראש פאנל השאלות יש שלושה כפתורים למעבר לשאלות של כל מסך: *מפת מדדים רשותית*, *דוח רשות*, *Data Explorer*.
- בתחתית כל מסך שאלות יש כפתור «המשך למסך הבא», ולאחר המעבר מוצגת **תזכורת להחליף את המסך גם בתוך הדשבורד**.
- סוגי שאלות: בחירה יחידה, בחירה מרובה, טקסט חופשי, ו"כן / לא" לכל אחד מחמשת הנושאים (נטענים מ-`data.js`). בשאלות עם «אחר» נפתח שדה טקסט להשלמה.
- התשובות נשמרות ב-`localStorage` תחת `kyd_molsa_workshop_v1` ונשמרות אוטומטית תוך כדי הקלדה. שם המשתמש והנפה נקראים מההזדהות של מסך תפיסת המדידה (`kyd_molsa_compass_v1`).
- כפתור **"ייצוא תשובות"** (וגם כפתור הסיום במסך האחרון) מוריד CSV עם: שם המשתמש, נפה, מסך, מזהה שאלה, שאלה, נושא, תשובה, פירוט («אחר»), עודכן.
- לשליחה לשרת — `SUBMIT_URL` בראש `assets/workshop.js`.

### הטמעת הדשבורד ו-HTTPS

`biportal` מוגש ב-HTTP. דפדפן לא מתיר לדף HTTPS להטמיע מסגרת HTTP (mixed content),
ולכן **בגרסה שרצה ב-Azure Static Web Apps הדשבורד לא ייטען לתוך המסגרת**. זו מגבלה
בדפדפן: אין הגדרה ב-Azure, כותרת HTTP או `staticwebapp.config.json` שמבטלת אותה, וגם
proxy לא יעזור כי ל-Azure אין גישה לרשת הפנימית.

**מצב שני חלונות** — הפתרון שמובנה בכלי. כשההטמעה נכשלת מוצע לפתוח את הדשבורד בחלון
נפרד (`window.open`), פעולה שאינה כפופה למגבלת ה-mixed content. אז השאלות תופסות את כל
רוחב החלון, ובראשן סרגל עם הבאה-לחזית / רענון / החזרה-לתוך-הדף. הבחירה נשמרת
ב-localStorage. מצמידים את שני החלונות עם `Win + ←` ו-`Win + →`.

פתרונות נוספים, לפי סדר עדיפות:

1. **להריץ את הכלי מכתובת HTTP** — אז ההטמעה עובדת כרגיל. לסדנה:
   `python -m http.server 8770` מתוך התיקייה. משתתפים באותה רשת יכולים להתחבר
   ל-`http://<כתובת-המחשב>:8770/workshop.html`. לשימוש קבוע: העתקת התיקייה ל-IIS פנימי.
2. **מדיניות דפדפן ארגונית** — `InsecureContentAllowedForUrls` ב-Edge/Chrome, עם
   הכתובת של האתר ב-Azure. IT דוחפים אותה ב-GPO והדשבורד נטען במסגרת גם ב-HTTPS.
   ידנית לכל משתמש: מנעול בשורת הכתובת ← הגדרות אתר ← Insecure content ← Allow.
3. **HTTPS ל-Report Server** — SSL binding ב-Report Server Configuration Manager עם
   תעודה שסומכים עליה בדומיין. הפתרון הנקי; כתובת ההטמעה כאן תלוית-פרוטוקול
   (`//biportal/...`) ולכן תעבוד מיד.
