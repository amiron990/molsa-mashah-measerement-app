# הקמת איסוף התשובות ל-Google Sheet

כשלוש דקות עבודה, פעם אחת. בסוף התהליך תקבלו כתובת — זה כל מה שצריך כדי לחבר את הכלי.

## 1. גיליון חדש

היכנסו ל-<https://sheets.new> בחשבון Google שבו תרצו שהתשובות יישמרו, ותנו לו שם —
למשל "מצפן רשויות מקומיות — תשובות סדנה". אין צורך להכין בו לשוניות או כותרות; הסקריפט
יוצר אותן לבד בהרצה הראשונה.

## 2. הדבקת הסקריפט

בגיליון: **תוספים ← Apps Script** (Extensions ← Apps Script).

⚠️ **חשוב שתפתחו את העורך מתוך הגיליון, ולא מ-script.google.com.** פרויקט שנוצר בנפרד
אינו מקושר לשום גיליון, ואז אין לאן לכתוב והלשוניות לא נוצרות. אם כבר יצרתם פרויקט
עצמאי — אין צורך להתחיל מחדש: מלאו את `SHEET_ID` בראש הקובץ במזהה מכתובת הגיליון,
החלק שבין `/d/` לבין `/edit`.

נפתח עורך עם קובץ `Code.gs` שמכיל פונקציה ריקה. **מחקו את כל תוכנו**, והדביקו במקומו את
כל התוכן של [`Code.gs`](Code.gs) מהתיקייה הזו. שמרו (Ctrl+S).

## 3. אישור הרשאות ויצירת הלשוניות

בסרגל העליון של העורך בחרו את הפונקציה **`setup`** ולחצו **Run**.

בפעם הראשונה Google יבקש אישור: **Review permissions** ← בחרו את החשבון ← מופיעה אזהרה
"Google hasn't verified this app" ← **Advanced** ← **Go to (שם הפרויקט)** ← **Allow**.
האזהרה תקינה וצפויה — זה סקריפט שכתבתם אתם, לא אפליקציה חיצונית.

בתחתית העורך ייפתח חלון Execution log ובו יופיע שם הגיליון ורשימת הלשוניות שנוצרו.
חזרו לגיליון: אמורות להופיע חמש לשוניות — `ratings`, `subvotes`, `answers`, `sessions`
ו-`log`.

**אם לא נוצרו לשוניות, קראו את השגיאה ב-Execution log:**

| השגיאה | המשמעות | הפתרון |
|---|---|---|
| `הסקריפט אינו מקושר לגיליון` | הפרויקט עצמאי ולא נוצר מתוך הגיליון | מלאו `SHEET_ID` בראש הקובץ, או פתחו עורך חדש מתוך הגיליון |
| `Authorization required` / לא נפתח חלון אישור | ההרשאות לא אושרו | הריצו שוב ואשרו: Advanced ← Go to… ← Allow |
| הרצה הסתיימה בלי פלט | לא נבחרה הפונקציה הנכונה | ודאו ש-**`setup`** נבחרה בתפריט שליד Run, ולא `doGet` |

לבדיקת כתיבה מלאה אפשר להריץ גם את **`testWrite`** — היא מוסיפה שורת בדיקה אחת
ל-`sessions` ול-`log`, שאפשר למחוק אחר כך.

## 4. פריסה כ-Web App

בעורך: **Deploy ← New deployment** ← לחצו על גלגל השיניים ליד "Select type" ובחרו
**Web app**. מלאו:

| שדה | ערך |
|---|---|
| Description | `איסוף תשובות סדנה` |
| Execute as | **Me** |
| Who has access | **Anyone** |

⚠️ **"Anyone" ולא "Anyone with Google account"** — המשתתפים לא מזדהים מול Google, ולכן
האפשרות השנייה תחסום אותם. הסקריפט רץ בהרשאות שלכם וכותב לגיליון שלכם; ה"Anyone" נוגע רק
ליכולת לשלוח אליו נתונים.

לחצו **Deploy**.

## 5. הכתובת

בסיום תוצג **Web app URL** בצורה:

```
https://script.google.com/macros/s/AKfycb.../exec
```

**זו הכתובת שצריך למסור.** פתחו אותה בדפדפן כדי לוודא — אמורות להופיע שלוש שורות:
`OK — נקודת קליטה פעילה`, שם הגיליון, ורשימת הלשוניות. אם מופיעה שם שגיאה במקום, היא
מצביעה על הבעיה — ראו הטבלה בשלב 3.

היא נשתלת ב-`assets/collect.js` בשדה `COLLECT_URL`, ומאותו רגע התשובות זורמות לגיליון.

## עדכון הסקריפט בהמשך

אחרי כל שינוי ב-`Code.gs`: **Deploy ← Manage deployments** ← עיפרון ← Version:
**New version** ← **Deploy**. הכתובת נשארת זהה.

⚠️ אם תבחרו "New deployment" במקום, תיווצר כתובת **אחרת** והכלי ימשיך לשלוח לישנה.

## הפסקת האיסוף

**Deploy ← Manage deployments** ← עיפרון ← **Archive**. הכתיבה נפסקת מיד, והנתונים
שנאספו נשארים בגיליון.

## מה נשמר

| לשונית | תוכן | מפתח |
|---|---|---|
| `ratings` | דירוגי כוכבים והערות על מדדים | משיב + מדד |
| `subvotes` | לייק/דיסלייק על תתי נושאים | משיב + נושא + תת נושא |
| `answers` | תשובות שאלות הסדנה, כולל שאלות המשך | משיב + שאלה + פריט |
| `sessions` | מי נכנס, מאיזו נפה ומתי | משיב |
| `log` | היסטוריה מלאה — כל שליחה, כולל ערכים שנדרסו | — (הוספה בלבד) |

ארבע הלשוניות הראשונות מתעדכנות במקום: משתתף שמשנה את דעתו מעדכן את השורה הקיימת. ההיסטוריה
המלאה נשמרת ב-`log`, כך שאפשר לראות גם מה היה קודם.

## אבטחה — מה שכדאי לדעת

`TOKEN` בראש הסקריפט חייב להיות זהה ל-`COLLECT_TOKEN` שב-`assets/collect.js`. הוא מסנן
פניות אקראיות, אבל **הוא מופיע בקוד המקור של דף ציבורי** — כלומר מי שמגיע לאתר יכול
לראותו ולשלוח נתונים לגיליון. לסדנה סגורה זה סביר. בסיום האירוע כדאי לארכב את הפריסה
(ראו למעלה) ובכך לסגור את הכתיבה לגמרי.
